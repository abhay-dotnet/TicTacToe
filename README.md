# 🎮 Tic-Tac-Toe – C# Console Game

Tic-Tac-Toe is a simple and interactive console-based game developed using **C# and .NET**. The project recreates the classic two-player Tic-Tac-Toe experience, where players take turns placing their symbols on a 3×3 game board with the goal of completing a row, column, or diagonal before their opponent.

The game is designed to provide a straightforward and engaging gameplay experience while demonstrating the practical use of fundamental C# programming concepts. Players can enter their moves through the console, and the game dynamically updates the board after every turn. The program keeps track of each player's moves and checks the game board after every turn to determine whether a player has successfully achieved a winning combination.

The project includes essential game logic such as **player turn management, move validation, win detection, draw detection, and game reset functionality**. It ensures that players cannot make invalid moves and continuously evaluates the current state of the board until the game reaches a winning or draw condition.

This project was created as a practical way to strengthen programming fundamentals and understand how logical problem-solving can be applied to build a complete interactive application. It provides hands-on experience with concepts such as **loops, conditional statements, methods, arrays, user input handling, and game-state management** in C#.

The Tic-Tac-Toe game can also serve as a foundation for future improvements. Possible enhancements include adding a **single-player mode with an AI opponent, difficulty levels, score tracking, replay options, improved console graphics, and a graphical user interface**.

Overall, this project demonstrates the implementation of a classic game using clean and understandable C# logic while providing practical experience in developing console-based applications with .NET.
